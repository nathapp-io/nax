## Acceptance criteria
- When PriorRunFailureProvider is constructed with no arguments, then construction succeeds.
- When a PriorRunFailureProvider is constructed, then its id is `prior-run-failure` and kind is `prior-failure`.
- When scoreChunk scores a prior-failure chunk, then it applies kind weight 0.85.
- When fetch finds no metrics file at request.repoRoot, then it returns empty chunks without throwing.
- When metrics records request.storyId as failed in a prior run, then fetch returns one chunk naming that story ID.
- When a requested story failed with two failingTestFiles, then its returned chunk names both files.
- When metrics never records the requested story as failed, then fetch returns empty chunks.
- When metrics records a failure only for a different story ID, then fetch returns empty chunks.
- When metrics.json is invalid JSON, then fetch returns empty chunks without throwing.
