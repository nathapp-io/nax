## Acceptance criteria
- When parseDiagnostics is called with a successful QualityCommandResult and tool name `tsc`, then it returns an array.
- When parseDiagnostics receives a tsc error for `src/a.ts` at line 12, then it returns one Diagnostic with file `src/a.ts`, line 12, and severity `error`.
- When parseDiagnostics receives a biome diagnostic naming a rule, then it returns one Diagnostic whose rule equals that rule name.
- When parseDiagnostics receives non-empty output for `unknown-linter`, then it returns exactly one Diagnostic with non-empty message and tool `unknown-linter`.
- When parseDiagnostics receives unknown-linter output longer than its bounded tail limit, then its one Diagnostic message length does not exceed that limit.
- When parseDiagnostics receives a successful QualityCommandResult with empty output, then it returns an empty array.
