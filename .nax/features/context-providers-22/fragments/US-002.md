- When a ToolDiagnosticsProvider is constructed, then its id is `tool-diagnostics` and kind is `diagnostics`.
- When scoreChunk scores a diagnostics chunk, then it applies kind weight 0.95.
- When scoreChunk scores a session chunk, then it applies kind weight 0.9.
- When ToolDiagnosticsProvider.fetch receives no storyScratchDirs, then it returns empty chunks.
- When ToolDiagnosticsProvider.fetch names a nonexistent scratch dir, then it returns empty chunks without throwing.
- When a scratch JSONL contains one malformed line and one valid tool-diagnostics entry, then fetch returns one chunk.
