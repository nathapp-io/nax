## Acceptance criteria
- When LintConfigProvider is constructed with no arguments, then construction succeeds.
- When a LintConfigProvider is constructed, then its id is `lint-config` and kind is `lint-config`.
- When scoreChunk scores a lint-config chunk, then it applies kind weight 0.8.
- When scoreChunk scores a static chunk, then it applies kind weight 1.0.
- When fetch reads a package containing biome.json, then it returns one chunk naming biome.
- When biome.json sets an indent width, then the returned chunk reports that indent width.
- When a package uses detected lint configuration without a distiller, then fetch returns a chunk naming the detected tool.
- When a package has no lint configuration source file, then fetch returns empty chunks without throwing.
- When no lint tool is detectable for a package, then fetch returns empty chunks without throwing.
