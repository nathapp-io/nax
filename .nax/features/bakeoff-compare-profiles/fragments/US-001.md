## Acceptance criteria
- When `validateContestants` resolves profile `cross-agent-pi`, then it returns `validAgents` containing `cross-agent-pi` and an empty `errors` array.
- When a named profile does not resolve, then `validateContestants` returns one error with reason `unknown-profile`.
- When one profile is unresolvable and another resolves in the same `validateContestants` call, then `validAgents` omits the unresolvable profile and retains the resolvable profile.
- When `validateContestants` rejects an unresolvable profile, then its error message contains that profile name.
- When `validateContestants` processes contestant names, then it invokes `loadProfile` once per name with that name as the first argument.
- When a resolved profile's `agent.default` is absent from the ACP adapter registry, then `validateContestants` returns reason `no-acp-adapter`.
- When a resolved profile's agent binary is absent from PATH, then `validateContestants` returns reason `dnf-not-installed`.
- When a profile overlay exclusively sets a configuration key, then the contestant merged config returns the profile value for that key.
