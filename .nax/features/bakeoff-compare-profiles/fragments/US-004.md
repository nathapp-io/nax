## Acceptance criteria
- When the PRD-tracking guard rejects a compare invocation, then `handleRunAction` creates no worktree.
- When a worktree ID is derived for a feature and profile, then it begins with `bakeoff-`.
- When a profile name contains characters outside the story-ID alphabet, then its derived worktree ID passes `validateStoryId` without throwing.
- When a feature and profile yield an overlong natural ID, then the derived worktree ID is at most 64 characters long.
- When two distinct feature-and-profile pairs both yield overlong natural IDs, then their derived worktree IDs differ.
- When preflight finds a leftover `nax/bakeoff-<id>` branch with no worktree record, then it removes that branch and subsequent worktree creation for the ID succeeds.
- When preflight runs with a branch not beginning `nax/bakeoff-`, then that branch still exists afterward.
