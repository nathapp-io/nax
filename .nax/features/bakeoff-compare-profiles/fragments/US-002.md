## Acceptance criteria
- When `runContestant` invokes its pipeline dependency, then the context `profile` equals the contestant profile name.
- When `runContestant` invokes its pipeline dependency, then the context `feature` equals the bake-off feature.
- When `runContestant` invokes its pipeline dependency, then the context `worktree` path ends with the contestant worktree ID.
- When a bake-off runs two contestants, then their pipeline contexts have different `worktree` values.
- When `runContestant` invokes its pipeline dependency, then the context `outputDir` equals the project output root joined with `bakeoff`, the feature, and the profile name.
- When a bake-off runs two contestants, then their pipeline contexts have different `outputDir` values.
- When `runContestant` invokes its pipeline dependency, then `context.config.outputDir` equals `context.outputDir`.
- When the pipeline dependency rejects, then `runContestant` returns status `dnf-crashed`.
