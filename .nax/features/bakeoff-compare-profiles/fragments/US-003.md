## Acceptance criteria
- When `handleRunAction` receives two resolvable profiles with a stubbed pipeline adapter, then the adapter is invoked exactly twice.
- When the pipeline adapter invokes `run`, then its `workdir` equals the context `worktree`.
- When the pipeline adapter invokes `run`, then its `prdPath` is located inside the context `worktree`.
- When the pipeline adapter invokes `run`, then its `prdPath` names the context feature.
- When the pipeline adapter invokes `run`, then its `statusFile` is located inside the context `outputDir`.
- When the pipeline adapter invokes `run`, then its `config` equals the context `config`.
- When `run` reports `storiesCompleted`, then the adapter returns a `results` array with that length.
- When the pipeline adapter executes a context, then it invokes `loadRunMetrics` with the context `outputDir`.
- When `loadRunMetrics` returns story metrics, then the adapter returns one metrics entry per story metric carrying that metric's cost and duration.
