2. **Three splits.** Spec §7.1 knows only whole-file Move/Stay/Unblock. S2-0 already split files the same way (nax-tree test blocks stayed in nax). A split moves whole blocks verbatim; test count is conserved.
3. **`tier-providers` AC1-AC6 and `bun-deps.test.ts` are reclassified Stay.** See the table. The SSOT's "8 blocked" therefore becomes 5 whole moves + 2 partial (AC8, plain-object) + 1 stay.

5. **nax keeps local copies of `command-safety` and `sandbox`** (spec §6.2: "an equivalent built on `/internal` in nax's own `test/helpers` (at most three files)"). Four staying nax tests use them. ## Review Focus

1. **A moved test that silently stops testing what it tested.** If `withWarnSpy` installs its spy somewhere the code under test does not log to, an assertion such as `expect(warned).toBeDefined()` fails, but an assertion that a warn did *not* happen would pass vacuously. Pinned in Task 2: the helper test proves a warn emitted through `getSafeLogger()` (the accessor `tool-audit.ts:187` and `launcher.ts:92` use) reaches the spy.
2. **A spy or logger that leaks into the next test.** nax's `withWarnSpy` reset the logger; the nax-agent one must restore the previous slot value even when the callback throws. Pinned in Task 2 (restore-after-reject test).
3. **A spy whose calls vanish when the callback resolves.** nax's helper deliberately keeps `spy.mock.calls` after resolve (AC-22 in acceptance-verdict-integrity). Pinned in Task 2.
4. **A split that drops or duplicates a test.** Pinned in Task 4: per-file pass counts before and after each split are compared to Task 0.
5. **A nax test still importing a removed helper subpath.** It would fail only at import time, under the full suite. Pinned in Task 5: `check-package-boundaries` no longer allows the subpaths, its test asserts that, and the full nax suite runs.

- [ ] **Step 3: Create `packages/nax-agent/test/helpers/agent-logger.ts`**

```ts
/**
 * Logger doubles for nax-agent's own tests. nax-agent logs through the logger
 * slot (`setAgentLogger` / `getSafeLogger`), so these install there.
 *
 * Same names and shapes as nax's `test/helpers/mock-logger.ts` and
 * `test/helpers/warn-spy.ts`, so a test that moves from nax changes only its
 * import specifier (S2-1).
 */
import { type Mock, mock } from "bun:test";
import { type AgentLogger, getSafeLogger, setAgentLogger } from "#src/infra/index";

type Level = keyof AgentLogger;
type LogFn = AgentLogger["warn"];
type LogSpy = Mock<LogFn>;

export type LogCall = {
  level: Level;
  stage: string;
  message: string;
  data?: Record<string, unknown>;
};

export type MockLogger = { [L in Level]: LogSpy } & {
  /** Every call made through this logger, in order. */
  calls: LogCall[];
  reset(): void;
};

export function makeLogger(): MockLogger {
  const calls: LogCall[] = [];
  const make = (level: Level): LogSpy =>
    mock<LogFn>((stage, message, data) => {
      calls.push({ level, stage, message, data });
    });
  return {
    error: make("error"),
    warn: make("warn"),
    info: make("info"),
    debug: make("debug"),
    calls,
    reset: () => {
      calls.length = 0;
    },
  };
}

const noop = (): void => {};

/**
 * Install a logger whose `level` method is a spy, run `fn`, then put back
 * whatever was installed before, even when `fn` throws. The spy keeps its
 * calls after `fn` resolves (callers may assert on it afterwards).
 */
async function withLogSpy<T>(level: "warn" | "info" | "debug", fn: (spy: LogSpy) => Promise<T>): Promise<T> {
  const previous = getSafeLogger();
  const spy: LogSpy = mock<LogFn>(noop);
  setAgentLogger({ error: noop, warn: noop, info: noop, debug: noop, [level]: spy });
  try {
    return await fn(spy);
  } finally {
    setAgentLogger(previous);
  }
}

export async function withWarnSpy<T>(fn: (warnSpy: LogSpy) => Promise<T>): Promise<T> {
  return withLogSpy("warn", fn);
}

export async function withInfoSpy<T>(fn: (infoSpy: LogSpy) => Promise<T>): Promise<T> {
  return withLogSpy("info", fn);
}

export async function withDebugSpy<T>(fn: (debugSpy: LogSpy) => Promise<T>): Promise<T> {
  return withLogSpy("debug", fn);
}
```
