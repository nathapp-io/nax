> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix three nax-agent-acp bugs: lost instructions after an early agent death (#2364), Claude's unasked plan-file write under `none`/`read` (#2366), and zero cost on errored or cancelled turns (#2367).

**Architecture:** nax-agent gains a public `attachTurnSpend` / `readTurnSpend` pair over the existing failure-usage WeakMap, and `turn_end` from an error carries `costSource`. nax-agent-acp attaches each failed turn's spend to the error it throws, settles the collector when a cancelled prompt still answers within the grace period, marks instructions delivered only on a turn-content update or a prompt response, and replaces Claude's plan mode under `none`/`read` with `default` mode, removed write tools and no settings files.

**Tech Stack:** TypeScript (ESM), Bun 1.4.0 workspaces, `bun:test`, `@agentclientprotocol/sdk` ~1.7.0, Biome.

**Spec:** `docs/superpowers/specs/2026-10-07-acp-fix-bundle-2364-2366-2367-design.md` (rulings F1-F7). Read it before starting.

```ts
/**
 * The spend a failed turn had already incurred, attached to the error it throws
 * (#2367). Keyed on the error's identity, so the error itself is rethrown
 * unchanged and keeps its own code. The facade's turn_end reads it on every
 * error path; the native loop writes it through recordNativeTurnFailureUsage
 * (nax#1840), an ACP backend through attachTurnSpend.
 */
import type { TokenUsage } from "#src/cost/standard-types";
import type { CostSource } from "./agent-session-types.ts";

export interface FailedTurnSpend {
  readonly tokenUsage: TokenUsage;
  readonly costUsd: number;
  readonly costSource?: CostSource;
}

const spendByError = new WeakMap<object, FailedTurnSpend>();

/** Attaches the spend a failed turn had already incurred to the error it throws. */
export function attachTurnSpend(err: object, spend: FailedTurnSpend): void {
  spendByError.set(err, Object.freeze({ ...spend }));
}

/** The spend attached to `err`, if any. */
export function readTurnSpend(err: unknown): FailedTurnSpend | undefined {
  return typeof err === "object" && err !== null ? spendByError.get(err) : undefined;
}
```

interface Spend {
  readonly usage: TokenUsage;
  readonly costUsd: number;
  readonly costSource?: CostSource;

function spendOf(err: unknown): Spend {
  const attached = readTurnSpend(err);
  if (attached !== undefined) {
    const { tokenUsage: usage, costUsd, costSource } = attached;
    return costSource === undefined ? { usage, costUsd } : { usage, costUsd, costSource };

}
